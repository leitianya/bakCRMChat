1. 检查 Socket 连接是否成功（浏览器控制台 Network/WS 中确认 WebSocket 是否连接到 `20108` 端口）。
2. 重置后台 token 后重新复制连接访问用户端。
3. 检查 Network 中接口返回是否有错误。
4. 若通过 nginx/Apache 反向代理访问，确认代理配置中带有 WebSocket 升级头（`proxy_set_header Upgrade $http_upgrade;` 与 `proxy_set_header Connection "upgrade";`），参见[站点配置](../安装/站点配置.md)。
5. 确认 swoole 进程正在运行：`php think swoole restart` 后观察启动日志是否报错。
