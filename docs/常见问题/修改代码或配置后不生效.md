改了代码或配置却不生效，九成是 Swoole 常驻内存导致的。

**原因**：Swoole 进程启动时会把代码、配置、composer 依赖加载进内存，之后磁盘上的文件变动不会自动加载。

## 处理方式

**宝塔/裸机环境：**

```
sudo -u www php think swoole restart
```

**本项目 Docker 环境：**

```
docker restart crmchat_swoole
```

## 哪些改动需要重启

| 改动 | 是否需要重启 swoole |
|---|---|
| 普通 HTTP 接口代码（控制器/services/dao 等，php-fpm 承载） | 不需要，即时生效 |
| WebSocket 处理（`app/webscoket/`） | 需要 |
| 队列任务（`app/jobs/`） | 需要 |
| 配置文件（`config/`，尤其 `swoole.php`） | 需要 |
| `.env` 环境变量 | 需要 |
| composer 依赖变更 | 需要（且建议 `composer dump-autoload`） |

## 还不生效？

1. 确认改的是挂载给容器的代码目录（本项目为 `crmchat/`）；
2. 查看启动日志是否报错：`docker logs -f crmchat_swoole`，或 `./run.sh logs`；
3. ThinkPHP 业务日志在 `crmchat/runtime/log/`，查看异常信息；
4. 浏览器端强制刷新（Ctrl/Cmd+Shift+R），排除前端缓存。
