安装后必须重启swoole。

**原因**：Swoole 是常驻内存进程，安装向导写入的数据库、Redis 等配置在启动时已加载进内存，不重启不会生效。

```
php think swoole restart
```

宝塔环境下请用 www 用户执行：

```
sudo -u www php think swoole restart
```

Docker 环境（本项目）执行：

```
docker restart crmchat_swoole
```

> 更多排查思路：若重启后仍提示数据获取失败，依次检查 MySQL/Redis 是否可连、`.env` 配置是否正确、`runtime` 目录是否有写入权限。
