## 命令行一键安装

### 安装命令

```
php think install
```

1. 首先配置根目录下的`.env`文件中的数据库连接配置（可复制`.example.env`为`.env`后修改）
2. 遇到如下提示，一般是`.env`中的配置问题，请检查数据库连接配置
![输入图片说明](https://images.gitee.com/uploads/images/2021/0722/173723_cb497bfc_1491977.png "屏幕截图.png")

3. 没有错误后会自动写入数据,如下图
![输入图片说明](https://images.gitee.com/uploads/images/2021/0722/173901_e7562522_1491977.png "屏幕截图.png")

4. 输入管理员账号密码
![输入图片说明](https://images.gitee.com/uploads/images/2021/0722/174657_5e14e73d_1491977.png "屏幕截图.png")

5. 提示'安装完成',请保管好账号密码
6. 如果已经安装过,重新安装时会自动备份数据库到根目录下的`backup`目录

### 启动swoole,已启动请重启swoole


```
sudo -u www php think swoole restart
```

### 恭喜,安装完成拉
