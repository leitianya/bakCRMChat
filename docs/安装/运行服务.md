### 步骤总结
一、切换PHP命令行版本和站点一致。
二、执行启动命令，启动swoole。

### 步骤详解

#### 一. 检测命令行PHP版本,如果不在7.1~7.4之间请按照以下教程切换;
1. 检测PHP版本,如达到要求直接跳过,直接进入 **启动命令** 
![输入图片说明](https://images.gitee.com/uploads/images/2021/0721/170114_bce29181_1491977.png "屏幕截图.png")
2.修改命令行PHP版本
![修改php版本](https://images.gitee.com/uploads/images/2021/0721/165913_79d49f40_1491977.png "屏幕截图.png")

3.选中使用的PHP版本(这里以PHP7.3为例)
![输入图片说明](https://images.gitee.com/uploads/images/2021/0721/170020_85668b51_1491977.png "屏幕截图.png")

#### 二. 启动命令
1.点击打开项目根目录
![输入图片说明](https://images.gitee.com/uploads/images/2021/0721/170312_fb54df55_1491977.png "屏幕截图.png")
2.点开左上角终端
![输入图片说明](https://images.gitee.com/uploads/images/2021/0721/170319_314219bf_1491977.png "屏幕截图.png")
3.执行swoole启动命令

```
php think swoole restart
```
展示如下界面,启动成功

![输入图片说明](https://images.gitee.com/uploads/images/2021/0721/170522_b6f2c105_1491977.png "屏幕截图.png")

启动成功后,则可关闭退出;
